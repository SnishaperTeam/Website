本页目录

总览 ​

本站（jetcpp.ccwu.cc）后端 API 的参考文档。后端运行在 Cloudflare Pages Functions 上（/api/* 路径），数据存储在 D1（可切换 Supabase Postgres）。

  • Base URL：https://jetcpp.ccwu.cc
  • 所有接口均以 /api/ 为前缀，请求与响应体均为 JSON（application/json; charset=utf-8）

认证 ​

除标注「公开」的接口外，均需在请求头携带 JWT：

Authorization: Bearer <token>
  • Token 由登录类接口返回（邮箱登录、第三方登录、设备登录），有效期 30 天
  • 算法 HS256；设备登录签发的 Token 额外携带 jti，设备被吊销后立即失效
  • Token 过期返回 401，需重新登录；账号被封禁返回 403

响应约定 ​

网站接口使用两种风格：

风格成功失败使用者
用户侧直接返回数据对象，如 { "user": ... }{ "error": "中文错误信息" }auth / posts / comments 等大部分接口
公告/管理侧{ "ok": true, ... }{ "ok": false, "error": "英文错误码" }notices / admin 系列

常用状态码：

状态码含义
400参数错误 / 请求格式错误
401未登录、凭证过期或无效
403无权限或账号被封禁
404资源不存在
409冲突（邮箱已注册、slug 已占用等）
429请求过于频繁（验证码、登录限流）

用户对象 ​

json
// PublicUser（公开，如 GET /api/users/:id）
{ "id": "uuid", "nickname": "昵称", "avatarUrl": "https://...", "createdAt": "ISO8601" }

// PrivateUser（仅本人/登录后，多一个 email）
{ "id": "uuid", "email": "a@b.c", "nickname": "昵称", "avatarUrl": null, "createdAt": "ISO8601" }
